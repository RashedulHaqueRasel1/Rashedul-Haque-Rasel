## 🛠️ Local Development

To run this project locally, follow these steps:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/RashedulHaqueRasel1/Rashedul-Haque-Rasel.git
   cd Rashedul-Haque-Rasel
   ```

2. **Install dependencies:**
   _(Ensure you have Node.js 20+ installed)_

   ```bash
   npm install
   ```

   _Note: The project also includes a `pnpm-lock.yaml`, so using `pnpm install` is recommended._

3. **Start the development server:**

   ```bash
   npm run dev
   ```

   The app will run using Turbopack and will be available at [http://localhost:3000](http://localhost:3000).

4. **Build for production:**
   ```bash
   npm run build
   ```
